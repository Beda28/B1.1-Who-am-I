# Who am I
```
본 프로젝트는 HTML, CSS, JS로 제작한 자기소개 웹페이지 입니다.
```

## 실행

`index.html`을 브라우저에서 실행하거나 Live Server를 사용합니다.

## 배포

GitHub Pages  
https://beda28.github.io/B1.1-Who-am-I/

## 주요 기능

- 반응형 레이아웃
- 다크 모드
- GitHub API를 이용한 공개 저장소 조회
- Contact Form 유효성 검사
- 스크롤 애니메이션
- 상단 이동 버튼

## 사용 기술

- HTML5
- CSS3
- JavaScript
- GitHub REST API
- GitHub Pages

## 학습 내용

- Flexbox와 Grid 레이아웃
- Media Query를 이용한 반응형 웹
- CSS 변수와 다크 모드
- DOM 선택 및 이벤트 처리
- Fetch API와 비동기 처리
- Form 입력값 검증
- IntersectionObserver를 이용한 스크롤 애니메이션
